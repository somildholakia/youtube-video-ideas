# YouTube Video Ideas

A source of truth for multiple YouTube channels, original series, characters, seasons, episodes and production assets.

## Structure
- channels/: channel identity and series
- Each series: canon, character library, worlds, technology, seasons and episode production packages
- docs/: designs and implementation plans

## Canon rules
1. Stable IDs are permanent and never recycled.
2. Approved reference images and the series bible are canonical.
3. The same detailed script drives image and audio generation.
4. Every shot/audio event has stable IDs and timecodes.
5. One image collage contains no more than 80 panels; each panel has a neat border and only a small sequence number beyond the story image.
6. Outlines are never labelled complete 40–45-minute scripts.
7. Review current YouTube policies and asset rights before publishing.
