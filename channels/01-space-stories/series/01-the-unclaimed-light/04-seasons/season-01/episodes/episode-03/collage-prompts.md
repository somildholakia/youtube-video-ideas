# S01E03 — The Garden That Remembers: ChatGPT Collage Prompt Sheet

This file is the image-generation hand-off for this episode. Generate collages in ChatGPT only, one request per batch. The canonical screenplay and shot-list CSV remain authoritative for each panel's story action and composition.

## Fixed prompt — paste into every generation request

Create ONE single landscape collage image with EXACTLY 80 distinct cinematic story-image panels arranged in a strict 10-column × 8-row grid. All panels must be equal-sized. Use a clean, clearly visible border/gutter between every pair of adjacent panels. Read panels left-to-right, top-to-bottom. Each panel contains only one story image and one small sequence number in a corner. The sequence number is the ONLY text allowed. No captions, dialogue, subtitles, titles, scene descriptions, labels, logos, watermarks, UI, interface text, pseudo-writing, decorative filler, unrelated objects or extra content outside the story frames. Do not merge panels, repeat images, omit frames or add extra cells. Maintain the exact approved character faces, hair, clothing, body proportions, Wayfarer geometry, props, location appearance, lighting and screen direction from the attached reference images. Use the episode's shot-list.csv for exact panel-to-shot mapping and visual instructions. This is a storyboard contact sheet, not a poster.

If you cannot render exactly 80 clearly separated panels, STOP and ask to split this batch into smaller grids. Do not silently return fewer panels or claim a malformed grid is complete.
